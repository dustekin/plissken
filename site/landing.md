# Plissken

A seven-part soundtrack sketch prototype for the M-VAVE FM-1: Juno-style chords, piano, Pro One-style synth,
guitar, bass, LM-1 samples, and a CS-50-style synth on one shared clock.

This is an early prototype. The arrangement is fixed, the drum kit uses three local samples, and the sound engines
and effects are intentionally simple. A selectable preloaded MIDI mode and additional graphics are planned.

**Never install an emulator-only firmware package on an FM-1.** Use a normal hardware-target build instead; the
emulator-only package is separately labeled but is not physically prevented from being installed.
